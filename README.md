# Studio CRM

CRM-система для студии разработки.

## Быстрый запуск

### 1. Установить зависимости и настроить БД

```bash
cd backend
npm install
npx prisma db push
node prisma/seed.js
```

### 2. Запустить бэкенд (порт 5000)

```bash
cd backend
npm run dev
```

### 3. Установить зависимости фронтенда

```bash
cd frontend
npm install
```

### 4. Запустить фронтенд (порт 3000)

```bash
cd frontend
npm run dev
```

Открыть: http://localhost:3000

**Логин по умолчанию:** admin@studio.kz / admin123

## Стек

- **Backend:** Node.js + Express + Prisma ORM + SQLite
- **Frontend:** React + Vite + Tailwind CSS + Recharts
- **БД:** SQLite (файл `backend/prisma/dev.db`)

## Модули

- **Дашборд** — горящие дедлайны, статистика
- **Проекты** — полное управление с командой и расчётом зарплат
- **Клиенты** — база с историей проектов
- **Лиды** — канбан-доска и список потенциальных клиентов
- **Сотрудники** — команда с процентами от проектов
- **Финансы** — транзакции и расходы
- **Аналитика** — месячный отчёт с графиками
- **Настройки** — налоговая ставка, валюта
